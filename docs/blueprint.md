# **App Name**: Bithumb DataLab Dashboard

## Core Features:

- Global Layout: Implement a boxed layout with a maximum width of 1440px and left/right whitespace.
- Header Customization: Modify the header with the 'Bithumb Data Lab' logo and Korean navigation menu (인사이트, 내부 데이터, 외부 데이터, 멤버쉽).
- Left Sidebar Navigation: Create a vertical sidebar menu on the left with crypto-related insights.
- Main Dashboard: Construct a main dashboard section with responsive grid-based widgets for displaying key metrics.
- 디지털 자산 시가총액 (Total Crypto Assets): Show a line chart with total crypto assets using mock data.
- 24시간 거래대금 (24h Volume): Display a bar chart for the 24-hour transaction volume of a crypto instrument, based on the past performance.
- 공포/탐욕 지수 (Fear/Greed Index): Visualize the Fear/Greed index using a Gauge/Speedometer chart. The value shows sentiment as extracted and evaluated by our LLM tool, running sentiment detection.

## Style Guidelines:

- Primary color: Orange (#FFB300), reflecting the Bithumb logo and brand identity.
- Secondary color: White (#FFFFFF) for card backgrounds and text containers to ensure readability.
- Background color: Light gray (#F8F9FA), providing a clean and neutral backdrop, similar to the Bithumb website.
- Body and headline font: 'Noto Sans KR' (sans-serif) for a clean and Korean-compatible look. Note: currently only Google Fonts are supported.
- Boxed layout with a max-width of 1440px and centered content for a structured presentation.
- Cards with white backgrounds, rounded corners, and subtle borders/shadows for a professional appearance.
- Use of simple, consistent icons for navigation and data visualization.
